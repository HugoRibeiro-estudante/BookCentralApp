# 📚 BookCentralApp

Plataforma completa para gestão de acervo literário, permitindo o controle de livros, autores e categorias. O projeto foi construído focando na integração entre um backend robusto em Java e uma interface dinâmica em JavaScript.

---

## 📋 Requisitos do Projeto

Para entender as regras de negócio e os requisitos funcionais deste sistema, acesse a documentação completa no link abaixo:

👉 [Documento de Requisitos Funcionais - Google Docs](https://docs.google.com/document/d/1UV7UnUwPQMMsDa6Lkf7rUJN57gdTu7lKYZLQyY45hRY/edit?usp=sharing)

## 🛠️ Tecnologias e Ferramentas
* **Backend:** Java com Spring Boot (Data JPA, Web).
* **Frontend:** JavaScript, HTML e CSS (Deploy na Vercel).
* **Banco de Dados:** H2 / PostgreSQL.
* **Ferramentas de Teste:** Postman (Collection inclusa no repositório).
* **Ambiente:** Docker e Gitpod (Configurações prontas para uso em nuvem).

## 🚀 Diferenciais do Projeto
* **Pronto para Testes:** Já inclui a collection do Postman para validar os endpoints da API imediatamente.
* **Cloud Ready:** Arquivos de configuração `.gitpod.yml` permitem abrir e rodar o projeto diretamente no navegador através do Gitpod.
* **Deploy Integrado:** Estrutura preparada para deploy contínuo em plataformas como Vercel.
